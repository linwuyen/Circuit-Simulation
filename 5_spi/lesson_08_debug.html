08. 症狀 → 原因除錯表

把前面所有觀念收斂成一張「查表」：輸入你看到的現象，它給你由高機率到低機率的檢查順序，以及該用什麼工具量哪裡。

🎯 一句話先懂

除錯不要亂槍打鳥。先看現象，依機率排序逐項排除：全 0/全 FF → 查 MISO 與 CS；位移 → 查 CPHA；高速偶發 → 查時序/訊號；連續掉 → 查 FIFO/ISR/DMA。

interrupt void spi_rx_isr(void)
{
    while (RXFFST >= WORDS_PER_PACKET) {
        read_one_packet_from_SPIRXBUF();
        push_packet_to_ring_buffer();
    }

    if (RXFFOVF == 1) {
        record_overrun_error();
        clear_rx_overflow_flag_in_TRM_order();
    }

    clear_rx_interrupt_flag_in_TRM_order();
}

串起來看
  • 讀不到東西（全 0/全 FF）→ 多半是接線 / CS / 選中（第 1、7 課）。
  • 位移、第一 bit 錯 → 多半是CPOL/CPHA / bit order（第 3、4 課）。
  • 低速好、高速錯 → 多半是時序餘裕 / 訊號完整性（第 4、7 課）。
  • 連續資料掉 → 多半是FIFO / ISR / DMA 吞吐（第 5、6 課）。
