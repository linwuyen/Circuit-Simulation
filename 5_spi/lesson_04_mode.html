04. CPOL / CPHA 四模式 + setup margin

把上一課的「取樣邊緣」整理成四種標準模式（Mode 0~3），並用一個小計算器估算：在你的速度與線路延遲下，setup 還剩多少餘裕、最高能跑多快。

🎯 一句話先懂

CPOL 決定 clock 閒置時是高還是低；CPHA 決定在第一個還是第二個邊緣取樣。兩個各 2 種，組合出 Mode 0~3。Master 與 Slave 一定要設成同一個 mode。

🪣 生活比喻

像兩個人約跳舞：CPOL＝起手是站著還是蹲著，CPHA＝聽到第一拍就動還是第二拍才動。只要兩人約定不一致，整支舞就會錯拍——SPI 對不上 mode 就是這種「錯拍」，常表現成 bit 位移或第一個 bit 錯。

📐 margin 是怎麼算的

看懂公式就會調

取樣邊緣大約落在半個 clock 週期之後。資料要在那之前穩定，所以：

margin = 半週期 − 資料延遲 − 需要的 setup − 保守裕量
最高 SCLK ≈ 1 / ( 2 × (資料延遲 + setup + 裕量) )

margin 變負，就代表「資料還沒站好就被拍照」，必須降速或縮短延遲。這也是為什麼長線、加隔離器後常常要把 SCLK 調慢。

✅ 自我檢查

讀回來的資料看起來像「左移了一個 bit」，最該先懷疑什麼？
位移類錯誤幾乎都是取樣邊緣對不上（CPHA）或 bit order 設錯。這種問題加 delay、開 FIFO 都救不了，要先把 mode 對齊。
