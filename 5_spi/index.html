建議學習順序

四個階段
  1. 先有畫面（00–02）：SPI 是什麼、四條線、一個 bit 換一個 bit。
  2. 搞懂時序（03–04）：clock 怎麼推資料、CPOL/CPHA 與最高速度。
  3. 資料量大（05–06）：為什麼要 FIFO、overrun 壓力測試。
  4. 動手實務（07–08）：接線與硬體錯誤、症狀除錯表。

先記住這幾個詞

中英對照
MOSIMaster 輸出、Slave 輸入。送命令或資料。
MISOMaster 輸入、Slave 輸出。讀回資料。
SCLKMaster 產生的時鐘，沒它就不交換 bit。
CS / STE選哪顆 Slave，常見低電平有效。
CPOL / CPHA決定 idle 電平與取樣邊緣，雙方要一致。
RXFFOVF接收 FIFO 滿了還進資料，代表已遺失。
