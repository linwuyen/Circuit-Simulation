2. 資料怎麼進來

Master 端
時鐘越快，FIFO 被填入的速度越快。
C2000 FIFO 通常以 16-bit word 計數。
Master 每筆資料後刻意停多久。
壓力測試用，常見於連續 burst 傳輸。

3. Slave 怎麼讀走

CPU / DMA 端
32-bit 資料會占 2 個 16-bit FIFO 格。
FIFO 到這個水位才叫 CPU 進來讀。
包含中斷延遲、ISR、搬資料與解析時間。
實務上 ISR 常會 while 迴圈把 FIFO 清到低水位。
