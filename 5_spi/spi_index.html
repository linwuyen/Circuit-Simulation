SPI 初學者互動課程

把 SPI 拆成四個能動手看的實驗：線路與資料位元、CPOL/CPHA 取樣、FIFO overrun、實機除錯。先建立直覺，再看暫存器與程式。

建議學習順序

1
先看線路和 full duplex理解 MOSI、MISO、SCLK、CS 各自做什麼，知道送資料與收資料同時發生。
2
再看取樣邊緣CPOL/CPHA 錯誤時，不一定完全沒資料，常見是位移、偶發錯、第一 bit 錯。
3
最後看 FIFO 與 CPU 速度FIFO 不是加速器，只是緩衝。平均讀走速度不夠，最後還是會 RXFFOVF。

互動模擬

01. SPI 訊號與資料流

用 8-bit 範例看 MOSI/MISO 如何同時交換資料，並練習 bit order、CS active low、dummy byte 的概念。

  • Step by step 看每個 clock 送哪一 bit
  • 看懂「寫一筆同時也會讀一筆」
  • 適合剛開始接觸 SPI 的人
打開第 1 課 -> 時序判斷

02. CPOL / CPHA 時序模式

把 Mode 0/1/2/3 轉成取樣邊緣與資料更新邊緣，並估算 setup margin 是否足夠。

  • 比較 Master 與 Slave mode 是否一致
  • 看 SCLK 太快時為何會偶發錯
  • 建立示波器量測方向
打開第 2 課 -> FIFO 計算器

03. FIFO、ISR、DMA 與 overrun

用 C2000 16-bit FIFO 概念估算 RXFFST、RXFFOVF、Master gap、CPU ISR 時間與 DMA 的影響。

  • 跑 4095 筆 burst 壓力測試
  • 比較無 FIFO、FIFO、Ready/Busy、DMA
  • 直接算建議 gap 與最高 SCLK

先記住這幾個詞

MOSIMaster 輸出、Slave 輸入。Master 寫命令或資料通常走這條。
MISOMaster 輸入、Slave 輸出。讀暫存器或讀資料通常走這條。
SCLKMaster 產生的時鐘。沒有 clock，SPI 就不會交換下一個 bit。
CS / STE選擇 Slave 的線，常見 active low。拉低後開始一段 transaction。
CPOL / CPHA決定 idle 電平、資料在哪個邊緣被取樣。雙方要一致。
RXFFOVF接收 FIFO 滿了還有新資料進來，代表資料已經遺失或覆蓋。
