關卡 05

波德圖的魔法：相乘變相加

開迴路 L(s) = C(s) × P(s) 本來要做複數乘法,很麻煩。但在 dB 上,乘法變成加法:把控制器曲線(灰)和受控體曲線(橘)上下相加,就是 L(s)(藍)。相位也是直接相加。

拖它,下面會逐項把這個頻率的「C + P = L」算給你看。

在游標頻率上，親手對帳

C(s)-- dB
P(s)-- dB
相加 =-- dB
實際 L(s)-- dB

「相加」和「實際 L」會一模一樣 → 證明 dB 上真的是加法。

💡 觀察重點

  • 任何頻率上,藍線高度 = 灰線高度 + 橘線高度。相位同理。
  • 所以「設計控制器」=拿一條你能改的灰線,去把固定的橘線抬到你要的形狀。
  • 橘線的諧振峰(凸起)會原封不動加到藍線上 → 這就是為什麼諧振峰甩不掉,只能設法別讓它碰到 0dB。
