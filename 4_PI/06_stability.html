把波德圖讀成「會不會翻車」——並親眼看時域

前 5 關都在頻域。但工程師真正在意的是時域:給一個指令,輸出追得快不快、會不會過衝振盪。這一關把兩邊並排,讓你看見 fc / PM / GM 三個數字怎麼決定右下角那條曲線。

🎚️ 一鍵情境（先感受差異）

三個關鍵指標

交越頻率 fc(頻寬／快慢) --
相位裕度 PM(離翻車距離) -- --
增益裕度 GM(諧振安全) --
→ 時域過衝量 --

💡 頻域 ↔ 時域對照

  • PM 大(>60°) → 右圖慢慢爬、不過衝。穩但拖。
  • PM 黃金(45~60°) → 右圖快速到位、幾乎不震。
  • PM 小(<30°) → 右圖衝過頭、來回震鈴。
  • PM ≤ 0 或 GM 不足 → 右圖振幅越來越大 = 發散翻車。試情境③。
