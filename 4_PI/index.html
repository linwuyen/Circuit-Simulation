逆變器控制 · 波德圖入門

從零讀懂 PI 控制器的波德圖

原本一頁塞了 8 個概念,初學者會被淹沒。這裡把它拆成 6 個小關卡,每一關只講一件事、只動 1~2 個滑桿,看得到因果。照順序走完,你就能自己設計控制器。

01

波德圖的「一個點」是什麼

丟一個正弦波進系統,輸出被放大幾倍、慢了幾度。把這件事看懂,波德圖就只是把所有頻率連起來而已。

學會：增益、相位、dB、為何用 log 頻率
02

積分器 Ki/s 的「指紋」

只看積分器：斜率永遠 −20dB/decade、相位永遠 −90°。它讓低頻超準,代價是吃掉相位裕度。

學會：積分=消穩態誤差，代價 −90°
03

加上 Kp → PI 控制器 C(s)

比例 + 積分合體。轉折頻率 fz = Ki/(2π·Kp) 決定「低頻用積分、高頻用比例」在哪裡交棒。

學會：Kp 與 Ki 各自的角色
04

LC 受控體 P(s) 會諧振

硬體本身(LC 濾波器)在諧振頻率會有一個放大峰。阻尼越小峰越尖越危險——逆變器最怕的就是它。

學會：諧振峰、阻尼 ζ、相位摔到 −180°
05

相乘變相加 → 開迴路 L(s)

波德圖最大的好處：在 dB 上,把控制器 C(s) 和受控體 P(s) 上下「相加」就得到 L(s)。

學會：L = C + P（在 dB 上）
06

穩定度 + 時域：fc / PM / GM

三個關鍵指標,並排顯示「給一個指令時輸出怎麼追上去」。親眼看到 PM 小 = 過衝振鈴。

學會：把頻域數字翻成真實的時域行為
★

設計沙盒（總複習）

走完 6 關後,回到完整模擬器自由設計。三個一鍵情境、即時健康度分析全在這裡。
