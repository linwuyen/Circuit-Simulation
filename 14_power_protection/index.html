Layer 4 · Protection & State

Protection 的核心是 Fault → Safe State 的最短可證明路徑

Threshold 只是起點。真正的 contract 包含 detection、filter/blanking、routing、PWM action、latch、logging 與 recovery ownership。

Fast Path

Comparator → Trip → PWM

適合要求 sub-cycle reaction 的 catastrophic fault；CPU 不必在 critical reaction path 上。

Measured Path

ADC → ISR → Decision

適合需要較多 context、平均、估測或 supervisory control 的 fault。

State

Latch / Re-arm

fault 消失不代表可以重開 power stage；recovery policy 必須符合 severity。

Sequence

Fail-Closed Startup

PRECHECK/READY/RUN 必須有 canonical owner，非法 transition 回 safe state。

第一性原理：保護要回答四件事：多久偵測？多久關掉能量？關掉後維持什麼 state？誰有權重新 enable？
