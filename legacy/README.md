# Legacy learning runtime

V2-related files are retained only for historical comparison and one-time migration compatibility.

They are not production entry points, must not be loaded by current HTML pages, and must not receive new features. New work belongs in the V3 schema, model registry, quiz bank, engineering models, runtime, and tests.

A future cleanup may move or delete legacy files only after retained user-state migration tests demonstrate that no supported progress data depends on them.
