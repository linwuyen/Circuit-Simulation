# Teaching Guide

## 拆解原則:第一性原理

BMS 的本質一句話:把電池關在安全範圍內,並決定高壓何時能接上負載。

順著這句話,一顆量測值會走過一條固定的因果鏈,每一環就是一頁:

| 頁 | 環節 | 學的那一件事 |
|----|------|--------------|
| 01 | 總覽 | 用一張圖看懂整條鏈 |
| 02 | 量測 | 感測值怎麼來、會被雜訊汙染 |
| 03 | 比較 | 把量測值和門檻比,產生判定(無狀態) |
| 04 | 決定 | 狀態機把判定變成動作 |
| 05 | 致動 | 預充時序,為何不能直接閉合主正 |
| 06 | 回報 | UDS 一問一答,讀懂 7F/NRC |
| 07 | 協同 | 多核怎麼安全交換資料(基礎層) |
| 08 | 失效安全 | 故意弄壞,看系統如何收斂到安全 |
| 09 | 整合 | 把整條鏈串成可重現的測試案例 |

## 建議流程

1. 開 `START_HERE.html` → 進 `index.html`。
2. 按 01 → 09 依序教,每頁只示範一個輸入與一個結果。
3. 用 `09_integrate.html` 當最後的整合演示。
4. 進階班再開 `legacy/tms320f28388d_bms.html` 三核心完整模擬器對照。

## 建議示範腳本

1. 在 `05_actuate.html` 按「開始預充」,等待進入 RUN。
2. 在 `04_decide.html` 注入過壓,觀察進 FAULT_LOCK。
3. 在 `06_report.html` 走完 `10 03 → 27 01 → 27 02 C3 D4 E5 F6 → 31 01`。
4. 在 `09_integrate.html` 把整條流程在同一頁重現一次。

## 每課的三層解說

每頁都用同一套三層問法:

- 我看到什麼?
- 在真實 BMS 裡這代表什麼?
- 程式 / 韌體裡是怎麼寫的?(對應暫存器 / #define / SID)

再加一句「如果這是你的車」,把抽象概念接回真實後果。
