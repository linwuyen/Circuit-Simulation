Lesson 02 · 鏈的第①環

量測是鏈的起點:AFE 提供數字,但它不替系統做安全決策。

本頁只練三個輸入:最高單體電壓、Pack 總電流、SPI 通訊品質。先把「感測值會被雜訊汙染、所以需要校驗」這件事看清楚,後面才有可信的數字拿去比較。

先記這三件事

輸入意義
最高單體電壓後面拿去和 OVP/放電上限比。
Pack 總電流後面拿去和 OCP 比。
SPI 錯誤計數累積到 3 次 = AFE 失聯,感測不可信。

操作任務

  1. 1
    把電壓拉到 4100 mV之後在「比較」頁會看到它落在可放電窗。
  2. 2
    把電壓拉到 4200 mV偏高灰帶,還沒過充。
  3. 3
    把電壓拉到 4300 mV越過 OVP。
  4. 4
    連按 SPI 錯誤累積 3 次就是失聯風險。
如果這是你的車:感測線受干擾導致一筆電壓被噪聲翻高,若不校驗就直接信任,系統可能誤判過壓而把你停在路邊。所以 AFE 用 CRC 把可疑資料擋下來。

AFE 輸入模擬

只改輸入,不做狀態機判斷
ADC_Read0x0FA0
Current Raw0x0000
SPI_Err_Cnt0
真實對應:ADC_Read = ADC 結果暫存器 ADCRESULTx(12-bit);門檻在韌體裡是 #define OVP_MV 4250、#define DISCHG_MAX_MV 4150、#define OCP_A 150。滑桿改的就是這些之後會被比較的數值。

事件紀錄

最新事件在最上方
AFE 已開始提供模擬輸入。

帶走這三句

  • AFE 是鏈的起點,只負責量測,不做安全決策。
  • 感測值會被雜訊汙染,所以需要 CRC 校驗才可信。
  • SPI 連續錯誤 = 失聯,後面的判斷必須當作「資料不可信」處理。
