# 一台電路，一個學習工作台

`index.html` 與 `learn.html` 現在直接開啟同一個工作台。八課使用同一份文件、同一個電路 SVG 與同一套完成規則；切課只改變問題、操作目標和必要的比較條件，不載入另一個課程頁面。

## 學生看到的流程

- 先記下預測，操作電路，辨認變化，判斷原因，最後換條件再試一次。
- 圖與操作保持在工作台；觀察步驟的提示放在曲線旁。手機可由曲線下方直接前往觀察問題。
- 新條件題先隱藏結果，通過後呈現同一模型的計算結果並保留設定。首次錯誤答案不會被重試覆寫。
- 從開關比例課轉到電感課時保留輸入電壓與開關比例。需要固定其他條件才能公平比較的課，先列出要改哪些設定，再由學習者套用。
- 完成一課即可自由探索。探索直接解鎖這張電路的控制項；返回課堂時恢復課堂設定，探索設定另存，重新進入探索時可續用。
- 個人進度、目前卡點與最近 20 次操作都在工作台內查看，不必跳到另一份能力地圖。
- 延伸教材依目前問題篩選，按需載入工作台內的參考區。它們仍有各自的模型，不自動將工作台參數套用到不相容的工具。
- 原有工程課與到期複習仍由統一推薦規則決定；可從工作台開啟。教師試用表位於教師入口，非學生必經步驟。

## 模型與進度

前五課與自由探索沿用既有 `CircuitTrainingExperiments` 理想降壓模型。後三課的數字修正規則維持明示的示意標記，電路本身不會套用那些修正比例。結束後自由探索會回到電路曲線。

仍寫入原 `benchmark.beginnerLessons` 與 `benchmark.bridgeLessons`，保留 `first`、`observationFirst`、`reasonFirst`、`transferFirst` 與正式測驗成績。工作台情境另存 `benchmark.learningWorkspace`，包含目前課程、電路設定、獨立探索設定與有限長度的變動紀錄，隨完整備份匯出。

舊的獨立課程網址繼續有效；首頁、能力地圖與跨頁導航推薦的八課入口，則統一導向工作台的課程片段網址。

驗證包含八課保持同一文件與同一 SVG、跨課設定保留、教學條件明確切換、自由探索往返、新條件不提前揭露答案、首次作答保留、內嵌教材與紀錄、手機排版及既有工程教材回歸測試。
