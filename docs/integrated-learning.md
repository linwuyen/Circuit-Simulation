# 統一學習路徑與共用案例

`learn.html` 是能力總覽；全站共用的「繼續學習」從既有紀錄計算下一步。`learning-case.html` 用同一組 Buck 參數連接電路、量測、時序、控制與頻率視圖。175 個教材／工具頁載入同一個導航元件；封存 originals 保持原樣，嵌入 iframe 內不重複顯示導航。

## 七個整合主題

| 主題 | 模組 | 共學概念 |
|---|---|---|
| 電路原理 | 0 + 入門 + 19 物理 | 開關、電感、電容、負載 |
| 量測 | 1、9、12 + 入門探棒 + 19 | 真實量 → AFE → ADC → 還原值 |
| 回授與動態 | 4、16、18 + 19 | 時間波形、频率響應、控制步驟 |
| 時序 | 6、13 + 入門 + 19 | 取樣 → 計算 → 更新 |
| 通訊 | 5、8 + 19 | 完整接收、發布、使用與新鮮度 |
| 保護與維修 | 7、14、15 + 19 | 偵測、關閉、鎖定、有條件復歸 |
| 應用遷移 | 2、3、10、11、17、19 | 電源、馬達、電網等專題 |

工具按能力分類，保留原有專題深入內容。模組 19 八層的既有順序與完成判準維持不變。已有主線紀錄者不強制重做入門；新學員先完成五課。可自行選擇起點。BMS、馬達與不同電源拓撲共用概念，但不共用不相容的模型或保護參數。

## 進度的唯一解讀層

`unified-learning.js` 讀取既有 Evidence V5、CoreFlow、beginnerLessons 和題庫 metrics，不複製或改寫各系統的成績。

- 首先推薦到期的正式 retention，其次既有題庫到期複習。
- 接著處理待完成補強與返回原任務，再依入門／主線／選修偏好接續。
- 入門練習、入門新條件、八層完成、原題庫 transfer／retention、正式 PRE／POST 分開呈現。沒有該類任務的主題不顯示空的計數。
- `benchmark.unifiedLearning` 只保存版本、學習偏好、補強往返與共用設定；沿用寫入失敗暫存與完整備份。
- 還原保留本機偏好與同模型設定；尚無的模型設定可由備份補入。原本首答與正式 protocol 的保護規則不變。

## 補強往返

只接受註冊 task ID，不能把任意網址當返回位置。物理、量測單位、時序、模型邊界對應既有補強分類。現場完成首次判斷、短實驗、新條件作答後，才能把往返標為可返回；匯入成績或單純瀏覽不觸發這個標記。返回後仍須完成原任務的判準，不直接授予 CoreFlow 完成。

進入輔助模組後，模組內的頁面連結保留 `learnFrom`。離開補強前也可以回到原任務；未通過時仍顯示待補強。可在能力總覽結束這次往返。

## 共用設定的模型契約

`buck-steady-v1` 僅接受白名單有限數值：Vin、duty、L、fsw、R、C、ESR。支援 `learning-case.html` 與 System Lab 下方固定 duty 模型。套用後重算結果，另開實驗，並重設量測儀器設定。上方閉環故障機器、入門固定題目、其他拓撲、控制工作台的設定不會被隱式改寫。

同一案例頁沿用現有 Buck 與 GuidedLayerModels：

- 開關波形：固定 duty 的二極體 Buck 穩態、小漣波，含既有 DCM／ESR 邊界。
- 量測：同輸出的分壓、量化與還原。
- 時序：每開關週期更新一次、嚴格早於更新點；算完不等於生效。
- 閉環時間視圖：同工作點的既有雙環平均模型，沒有新加硬體等待延遲。
- 頻率視圖：同工作點的開環功率級與純延遲，沒有 PI，因此不宣稱閉環 phase margin。DCM、非零 ESR 或超出小漣波條件時，停用不適用的 CCM 視圖。

共用的是參數與學習情境；不同模型鏡頭明示差異，不把不同物理假設強行視為等價。

## 詞彙與維護

`learning-glossary.js` 是共用白話詞彙來源；入門頁直接使用，原課程 glossary 的對應術語也套用同一解釋。新增模組時更新 `learning-map.js` 與 stage 歸屬，新增可返回任務時註冊 task ID。新增模型需另設 family/version，不能擴大既有 family 的含義。

## 驗證

`tests/unified-learning.test.mjs` 驗證推薦順序、20 模組覆蓋、模型拒用、備份與成績界線。`tests/e2e/unified-learning.spec.js` 驗證桌面／手機導航、跨頁設定、現場補強往返、鍵盤操作、版面與非法返回來源。完整專案 CI 保留既有課程、工程模型、韌體與瀏覽器檢查。實際學習效率與教學成效仍需真人試用測量。
