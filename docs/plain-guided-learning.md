# 一步一步學：教學整合與試用

八課現已進一步整合為[同頁工作台](integrated-workspace.md)，以下保留學習判準與真人試用方法。

首頁 `index.html` 與 `learn.html` 現在呈現同一個白話入口：目前那一課、要做的下一步，以及一個主要按鈕。完整教材移至 `catalog.html`，能力地圖與正式紀錄位於 `map.html`，均可從首頁的進階入口開啟。

## 八課與共同流程

1. 開關打開的時間怎麼影響輸出。
2. 關閉開關後，電流是否立刻停止。
3. 用電變少時，是否出現零電流區間。
4. 分辨電路真的改變與儀器顯示改變。
5. 分辨算完與命令生效。
6. 用目標減量測，描述還差多少。
7. 每輪重新量測，再補上一部分差距。
8. 辨認調整過多造成的來回變化。

每課依序顯示「先猜、觀察、說原因、換條件」。未來步驟不能跳過，已完成步驟可重看。預測錯誤不阻止學習，也不會在重試後被改寫為首次答對。操作到指定數值只記錄操作；正確辨認觀察、正確判斷原因、通過新條件題後，才算完成本版練習。

後三課只使用簡化的數字修正規則，不是實際 Buck 的閉環模擬，也不能拿比例直接設定真實控制器。完成八課不代表獲得正式工程能力認證。正式測驗與八層工程課的既有成績保持獨立。

## 舊進度與備份

舊版首次預測、新條件首次答案與通過狀態全部保留。新版首頁會請已完成舊課但沒有觀察與原因紀錄的人補做這兩個判斷，不偷偷把歷史作答改成答對。新版互動標記 `edition: 2`，完成證據放在 `proof.observation` 與 `proof.reason`。三堂銜接課使用 `benchmark.bridgeLessons`，納入原本的完整備份；合併備份不覆寫本機已有的首次作答。

## 自由實驗與補強

`learning-case.html` 自動與上一份有效設定比較，含輸出、電流、更新時刻、還原量測與恢復曲線。灰色虛線和綠色實線使用共同座標。無效輸入不會破壞前一份比較；不同模型的適用條件仍然分開檢查。只有有明確對應的錯誤分類才提供外部短實驗，其餘使用原題內的補強，不再預設送往不相關的模型題。

## 實際學習者試用

工具：`teaching-review.html`。本版本提供觀察表，沒有聲稱已完成真人試用。

- 找有不同經驗的學習者，使用匿名代號。請對方從首頁自行找出下一步，完成一課；首次嘗試時觀察者先不提示。
- 記下找不到的按鈕、不懂的詞、看不懂的圖，以及每次需要提示的位置。讓對方說出前後變化，再用自己的話解釋原因；勿只依選擇題答對判定理解。
- 換一組題目中的條件，請對方獨立判斷。若需要提示，記「需要提示」，不要記成獨立完成。
- 計時只記本次觀察時間，不代表能力分數。未觀察的項目明確保留為「未觀察」。離開頁面前下載 JSON；頁面不會自動傳送資料。
- 根據反覆出現的卡點修改教材，再找下一批學習者重試。小規模觀察能找出問題，不能證明教學效果的因果提升；若要比較效果，另設一致的前後測、觀察條件與延後測驗。

驗證包含數字修正規則、進度門檻、首次作答保留、備份合併、八課操作、前後比較、無效輸入、手機排版與匿名觀察匯出。
