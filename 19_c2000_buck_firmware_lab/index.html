MECHANISM

公式只在你看過現象之後出現

D = Vout / Vin

理想 CCM steady-state Buck 的 volt-second balance。

(di/dt)ON = (Vin − Vout) / L

L 越大，同樣電壓下電流斜率越小。

ΔIL = (Vin − Vout)·Ton / L

所以只增加 L，ripple 反比下降。

φdelay = −360°·fc·Td

这里只算純 delay contribution，不冒充 total phase margin。

P0 · C2000 BINDING

Target 必須真的形成閉環

  • ePWM：TBCLK / UP-count / CMPA shadow@ZERO / AQ high@ZERO low@CMPA 明確配置。
  • ADC：prescaler / 12-bit single-ended / enable converter / ≥500 µs startup / Vout+Vin+iL SOC。
  • Safety：CMPSS1 CTRIPH → ePWM XBAR TRIP4 → DCAEVT1 async → TZ LOW。
  • Command：只有 communication owner 呼叫 `BuckTarget_publishCommand()` 才刷新 heartbeat。
  • Startup：software OST 先把 PWM fail-closed；fresh validated enable 才解除。
