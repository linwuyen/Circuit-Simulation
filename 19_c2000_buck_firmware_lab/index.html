MECHANISM

公式只在你看過現象之後出現

D = Vout / Vin

理想 CCM Buck volt-second balance。

(di/dt)ON = (Vin − Vout) / L

L 越大，同樣電壓下電流斜率越小。

Gvd(s)=Vin/(LCs²+(L/R)s+1)

把 plant dynamics 與 controller 分開。

φdelay = −360°·f·Td

純 delay contribution，不冒充 total phase margin。

timeout fault ⇔ enable ∧ age > budget

和 C controller 的 strict greater-than semantics 一致。

fRHP=R(1−D)²/(2πL)

Boost CCM 的遷移限制。

C2000 BINDING

Target 必須真的形成閉環

  • ePWM：TBCLK / UP-count / CMPA shadow@ZERO / AQ 明確配置。
  • ADC：prescaler / mode / startup / Vout+Vin+iL SOC；overflow 使 sensor truth 失效。
  • Safety：CMPSS1 CTRIPH → TRIP4 → DCAEVT1 async → TZ LOW，並鏡射進 software OCP latch。
  • Command：只有 communication owner publication 才刷新 heartbeat；clear-fault 用 release→assert token。
  • Calibration：未明確提供 BUCK_BOARD_CALIBRATION_VALID=1 時 fail closed。
  • Flash：codestart 位於 0x080000，link map/HEX 由 CI 驗證。
