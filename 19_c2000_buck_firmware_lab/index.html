從方程式到 ePWM / ADC / CMPSS / Trip Zone，再到 HIL 證據

同一個 Buck controller 同時存在三個世界：host SIL 的純 C 控制核心、C2000Ware driverlib 的 target binding、以及可注入 fault 的 deterministic HIL model。

1 · 真正的 sample → compute → actuate pipeline

ePWM1 SOCA
TBCTR = ZERO→ ADCA SOC0
S/H + EOC→ ADCINT1 ISR
GPIO31 evidence→ BuckControl_tick()
CC/CV + anti-windup→ CMPA update
PWM command
CMPSS1→Digital Compare→Trip Zone→PWM LOW

Safety plane 不等 control ISR：過流硬體路徑必須能直接否決 PWM。韌體負責留下 evidence、state 與 re-arm policy。

2 · Source contract

純 controller 不碰 register；target binding 只做 hardware ownership。這樣同一份 controller 可以先在 host SIL 證明，再接進 C2000。
