輕載會怎樣：CCM vs DCM

一句話：負載拉很輕時，三角波的谷會想低於 0，但二極體擋住反向電流，電流就停在 0 → 進入 DCM。

🟣 聚焦：二極體 D（只准電流單向 → 擋住反流）
2.0 A
↓ 負載越輕，平均線越低 → 谷值越接近 0
本頁固定：Vin = 12 V、Vout = 3.3 V、L = 2.2 μH、Fsw = 500 kHz
電感電流 I_L（綠＝平均＝Iout）▲ DCM
ON 充電 OFF 續流 斷流死區
🔧 動手試：從 2 A 慢慢往左拖。先看谷值一路降到碰 0A（CCM 的臨界點）。再往下拖，波形會「觸底躺平」一段 —— 那就是 DCM 的斷流死區，三角形不再被綠色平均線對半切。
📌 帶走這句：谷值 = Iout − ΔI/2。當它想低於 0，二極體擋掉反向電流 → 電流卡在 0 → DCM。DCM 下系統的轉移函數變了，原本在 CCM 調好的 PID 不一定還穩 —— 這就是第 5 頁韌體要處理的坑。
