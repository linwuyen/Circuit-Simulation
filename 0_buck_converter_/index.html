降壓轉換器 Buck：互動教學地圖

把一顆 buck 從「為什麼能降壓」一路拆到「韌體怎麼採樣控制」，一頁只講一件事。

建議從第 0 頁照順序往下走。每頁都有電路圖、可拖動的滑桿、和一句帶得走的結論。純前端、可離線開。

Buck 在做什麼？切碎再撫平

開關把高電壓「切」成方波，平均下來就是低電壓。先建立最核心的一條式子。

滑桿：Duty、Vin　→　Vout = D × Vin

電感為什麼吐三角波電流

電感鐵律 V = L·(dI/dt)：電壓決定電流爬升的斜率。一上一下就是三角波。

滑桿：Vin、Vout、L　→　兩段斜率 m₁ / m₂
→
2

電流漣波 ΔI，怎麼把它變小

三角波的峰−谷高度就是漣波。看 L 變大、開關變快時，它怎麼縮小。

滑桿：L、Fsw　→　ΔI = (Vin−Vout)·D /(Fsw·L)
→
3

電容把電流漣波撫成電壓漣波

漣波電流灌進輸出電容，變成輸出電壓的小抖動 ΔVout。電容越大越穩。

滑桿：ΔI、C、Fsw　→　ΔVout = ΔI /(8·Fsw·C)
→
4

輕載會怎樣：CCM vs DCM

負載太輕時電流會觸底歸零，進入 DCM。二極體擋住反向電流是關鍵。

滑桿：Iout　→　谷值碰到 0 就切換模式
→
5

進階：韌體 / 控制觀點（綜合模擬器）

把前五頁合起來：ADC 採樣點、DCM 下 PID 為何震盪、開關損耗取捨。前面都懂了再來。
