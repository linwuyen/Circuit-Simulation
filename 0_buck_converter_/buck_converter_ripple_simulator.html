怎麼看懂這張圖（從頭講起）

降壓轉換器（buck）把高電壓「切碎」再用電感+電容平滑成低電壓。開關不停 ON / OFF，電感是主角：它把「電壓」累積成「電流」。

  • 為什麼電流是三角波？ 電感鐵律 V = L·(dI/dt)：電感兩端有多少電壓，電流就以固定斜率爬。ON 時承受 (Vin−Vout)，以 m₁ = +(Vin−Vout)/L 上升；OFF 時二極體續流、承受 −(Vout+Vd)，以 m₂ = −(Vout+Vd)/L 下降。一上一下＝三角波（單位上 V/µH 剛好＝ A/µs）。
  • 漣波 ΔI 就是三角波峰−谷高度（圖左標尺）。ΔI = (Vin−Vout)·D/(Fsw·L)：L 越大、Fsw 越高 → ΔI 越小。
  • 綠線＝平均電流＝Iout。 CCM 時剛好把三角形對半切。
  • ADC 採樣（紅點 vs 橘圈）：紅點採在 ON 中點，CCM 剛好＝平均、又離切換邊緣最遠（避雜訊）；橘圈採在週期邊界，只採到谷值。一進 DCM，紅點掉到 I_pk/2、橘圈在 0，兩者都離開綠線 → 固定採樣時間在 DCM 會失準。
  • 輸出電壓漣波 ΔVout（下方綠波）：電感漣波電流灌進電容變成電壓抖動，ΔVout = ΔI/(8·Fsw·C)。C 越大 → ΔVout 越小。
  • CCM vs DCM：Iout 拉低使谷值要低於 0 時，二極體擋反向電流，電流停在 0（斷流死區，灰色）。此時責任週期縮短、峰值改變、三角形不再被平均線對半切。

韌體觀點 (Firmware Insight)

  • Ripple 太大：ADC 採到的電流抖動變大（SNR 變差），電流環看到的訊號變髒。
  • DCM 模式：波形觸底使系統轉移函數改變（pole 移動），同一組 PID 在 CCM 穩、在 DCM 不一定穩，可能震盪。
  • 採樣點：放在 ON 中點，CCM 採到平均又避開 switching noise；但 DCM 下 ON 中點＝I_pk/2≠平均（紅點離開綠線）——固定採樣在 DCM 失準，這是電流偵測常見的坑。
  • 提高 Fsw 的代價：ΔI、ΔVout 變小、可用更小的 L/C，但開關損耗隨 Fsw 上升（上方趨勢條），是效率與體積的取捨。

名詞速查

Duty / 佔空比 D一週期裡開關 ON 的時間比例。CCM 約 Vout/Vin。
Ripple / 漣波 ΔI電感電流的峰−谷抖動量；越小越乾淨。
ΔVout輸出電壓的抖動量＝ΔI/(8·Fsw·C)。
CCM 連續導通電感電流整週期 > 0，不歸零。
DCM 斷續導通輕載時電流每週期觸底到 0 並停留死區。
m₁ / m₂ 斜率上升 +(Vin−Vout)/L、下降 −(Vout+Vd)/L，單位 A/µs。
