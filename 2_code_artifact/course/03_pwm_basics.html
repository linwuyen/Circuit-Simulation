⏹️ PWM 與平均電壓

📍 課程地圖

🎯 本課目標

理解 PWM（脈寬調變）的核心魔法：開關只會「全開」或「全關」，但只要快速切換、控制導通時間的比例（占空比），輸出的平均電壓就能是任何你想要的值。一句話：平均輸出 ≈ 占空比 × Vdc。它怎麼產生？用一個比較器：參考波 vs 高頻三角載波。

🔬 動手做

  1. 已打開 CH4：紅色是參考波、灰色是三角載波。規則很簡單：紅 > 灰 → 開關 ON。
  2. 看綠色 CH1：它就是被「切」出來的方塊脈衝。注意在參考波高的地方，脈衝變寬（導通時間長 → 那段平均電壓高）。
  3. 拉 載波頻率 fc 滑桿調高 → 單位時間內脈衝變多、變細；調低 → 脈衝變少、變粗。
  4. 拉 ma（參考波幅度）→ 整體脈衝寬窄跟著變，平均電壓也跟著變。

✅ 你應該看到 / 為什麼

輸出永遠是離散的方塊（只有 +/− 兩個準位），但脈衝寬度隨參考波改變。把這些脈衝在一個載波週期內「平均」，得到的就是參考波的形狀。

這就是「用數位的開/關，合成出類比的平均值」。載波頻率越高，平均得越細、越接近理想，但開關次數變多 → 切換損耗上升（這是下面的取捨）。

🌍 這在真實世界用在哪

  • 馬達調速、LED 調光、DC-DC 轉換、D 類音響放大器，全都靠 PWM。
  • MCU 內的「比較暫存器 (CMP)」就是這個比較器：你寫一個數字進去，硬體自動產生對應占空比。
  • TI C2000 ePWM 的計數器 = 三角載波，CMPA = 你的參考值。

⚖️ 工程取捨：載波頻率怎麼選？

fc 拉高：平均更平滑、濾波器可以更小、噪音超出聽覺範圍；但每次開關都有損耗，fc 越高 → 切換損耗與發熱越大、效率下降。這就是為什麼工業變頻器常用 2~16kHz，而不是越高越好。

❓ 考考你

占空比 50% 時，半橋輸出的平均電壓是多少？
約 0V。因為一半時間 +Vdc/2、一半時間 −Vdc/2，平均相消。占空比要 > 50% 平均才為正。
為什麼不直接用「線性穩壓」把電壓降到想要的值，而要用 PWM 開關？
線性穩壓靠電阻分壓，多餘能量全變成熱，效率低。PWM 開關理想上不耗能（全開時無壓降、全關時無電流），效率可達 95%+。
把 fc 調到跟基波 f 很接近，會發生什麼？
一個基波週期內只有幾個脈衝，平均得很粗糙，輸出諧波嚴重、難以濾波。所以 fc 通常是 f 的數十到上千倍。
