🪜 半橋臂與直通短路

📍 課程地圖

🎯 本課目標

認識電力電子最基本的積木——半橋臂 (Half-Bridge / 一條 leg)：一個上管、一個下管，輪流把輸出點接到正母線或負母線，產生 +Vdc/2 或 −Vdc/2。同時親手「製造」一次最致命的錯誤：直通短路 (Shoot-through)，理解為什麼真實電路一定要留死區時間。

🔬 動手做

  1. 手動模式下，點 Q1（或捷徑「上管 Q1」）→ 輸出 CH1 跳到 +50V（接上正母線）。
  2. 點「柵極全關」，再點 Q2 → 輸出跳到 −50V。這就是一條 leg 的兩種狀態。
  3. 製造災難：同時把 Q1 和 Q2 都點亮（直接點電路圖兩個開關）→ 紅色直通短路警告會跳出來！
  4. 清除後，按 「自動 PWM 控制」，把調變策略切到「方波」→ 看 leg 自動上下交替。

✅ 你應該看到 / 為什麼

一條 leg 的輸出永遠是 +Vdc/2 或 −Vdc/2 二選一，參考點是電容分壓的中性點 N。

當上下管同時導通，正負母線之間只剩開關的微小內阻，電流瞬間衝到數千安培 → 開關熱擊穿炸毀。所以真實的閘極驅動一定會插入 死區時間 (dead-time)：先確定一管完全關閉，才允許另一管開啟。

🌍 這在真實世界用在哪

  • 幾乎所有逆變器、變頻器、馬達驅動，每一相都是一條這樣的 leg。
  • TI C2000 的 ePWM 模組有專門的「Dead-Band (DB)」子模組，硬體自動插入死區。
  • 同步降壓 (Buck) 的上下管也是一條 leg，差別只在控制策略。

⚖️ 工程取捨

死區時間太短 → 可能直通短路、燒管；太長 → 輸出電壓被「吃掉」一小塊，造成死區失真 (dead-time distortion)，低速時馬達會抖動、電流出現尖角。實務上要依開關的關斷時間，取「夠安全又夠小」的值（常見 0.5~3µs）。

❓ 考考你

半橋輸出的「0V」參考點實際上在哪裡？
在兩顆分壓電容 C1、C2 的中點，也就是中性點 N。所以輸出在 +Vdc/2 與 −Vdc/2 之間擺動，而不是 +Vdc 與 0。
為什麼上下管「同時導通」是致命的，而「同時關斷」卻安全？
同時導通 = 母線被金屬性短路 → 數千安培 → 炸毀。同時關斷時電流沒有短路路徑，電感電流會改走反並聯二極體續流（第 1 課學過），是安全的。
死區時間設太大，會在輸出波形上看到什麼？
輸出基波被削弱、波形在過零點附近出現「平台或尖角」——死區失真。需要靠軟體補償（dead-time compensation）。
