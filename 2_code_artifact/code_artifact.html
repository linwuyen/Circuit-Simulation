📊 這三個數字代表什麼？（新手點我）

Vrms：輸出電壓的「有效值」，代表整體電壓大小（含所有成分）。

V1,rms：其中真正有用的基波（你設定的那個 50/60Hz 正弦）的有效值。

THD：總諧波失真——基波以外的「雜質」佔基波的比例，越低代表波形越乾淨。

💡 重點是「比較」：固定其他設定、只切換調變策略，看數字怎麼變。這是濾波前的橋臂電壓，數值偏高很正常；接上 LC 濾波器後負載端會乾淨許多。
