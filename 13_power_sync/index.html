Layer 3 · Timing & Control

PWM、ADC、ISR、Duty Update 必須畫在同一條時間軸

數位控制真正的 plant input 不是「C code 算出的 duty」，而是 PWM hardware 在某個 load event 真正採用的新 compare value。ADC sample 也不是 ISR 讀值的時刻，而是 SOC 後 sample-and-hold aperture 所對應的 physical instant。

1 · Trigger

PWM → SOC

用 time-base event 決定 sample phase；先問「量到哪個 switching state」。

2 · Convert

Acquisition + Conversion

sample capacitor 充電與 ADC conversion 都需要時間，資料不是 SOC 當下就 ready。

3 · Compute

EOC → ISR → Control

控制演算法必須用 worst-case execution / jitter 做 deadline，而不是平均值。

4 · Actuate

Shadow Load

ISR 算完後如果錯過 load point，新 duty 可能下一週期才真正生效。

第一性原理：closed-loop latency = measurement age + conversion + scheduling + computation + actuation delay。只看 CPU execution time 會漏掉一半因果鏈。
A-capable：關閉 same-cycle timing避開 switching edge找一拍 shadow delay
