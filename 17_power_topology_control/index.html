A-CAPABLE LAB · BASELINE PLANT

Buck：先用最乾淨的拓撲建立控制骨架

Exact ideal identity + teaching AC model
① 白話

開關 ON 時電感充能，OFF 時電感繼續送能量。穩態時電感一個週期平均電壓必須是 0。

② 數學

Ideal CCM：Vout=D·Vin。AC plant 主要由 L、C、R 形成二階系統，capacitor ESR 再加一顆 zero。

③ C2000

ePWM SOC → ADC sample IL/Vout → PI/2P2Z → CMPA shadow。sample 與 load event 位置會直接變 delay。

④ Debug

模型 pole 對、phase 卻整段少一截：先查 ADC filter、ISR latency、PWM commit，不要先怪 PI。

NON-MINIMUM-PHASE PLANT

Boost CCM：你第一次遇到「想加速，輸出卻先往反方向」

RHP zero cannot be cancelled
① 白話

Duty 突然增加時，電感先多花時間充能、少花時間把能量送到輸出，所以 Vout 短時間可能先掉，再慢慢升。

② 數學

CCM control-to-output 有 RHP zero；它的 magnitude 像 zero 往上抬，但 phase 卻往下掉。

③ 設計

保守 crossover 通常要明顯低於 RHPZ；這不是多塞一顆 LHP zero 就能互消的問題。

④ Debug

負載變重或 duty 變大時 RHPZ 可能下移；同一組補償器會突然變得難看。

MULTI-TIME-SCALE CONTROL

PFC：不是「穩住 400 V」而已，還要讓輸入電流像輸入電壓

Dual-loop teaching model
① 白話

內環負責「每個 switching cycle 把電流拉成想要的樣子」；外環只慢慢決定這個正弦電流要多大，讓 bus 能量收支平衡。

② 頻率分工

line 50/60 Hz 會自然產生 100/120 Hz 的瞬時功率 ripple。外環若拼命追它，current amplitude reference 也會被調制。

③ C2000

SPLL / line feed-forward → current reference；ADC 同步 sample current → current compensator → PWM；Vbus 外環在更慢時間尺度更新 amplitude。

④ Debug

Bus 看起來超穩、THD 卻爛：先懷疑 outer loop 太快，而不是只看 current PI。

ISOLATED · PHASE-SHIFT CONTROL

PSFB：控制量不是「一個 MOSFET 的 duty」，而是兩個 bridge leg 的相位

Power transfer + ZVS energy teaching model
① 白話

兩個 half-bridge 都近似 50% duty，但把它們彼此錯開多少角度，決定 transformer primary 有效電壓存在多久。

② 一階估算

用 normalized phase mφ=φ/180° 當 effective transfer command，Vout≈n·Vin·mφ；實機還會有 commutation duty-loss。

③ ZVS

橋臂切換前要有足夠電流/漏感能量去充放 Coss。輕載時 energy 不夠，就會失去 ZVS。

④ Debug

看 Vds turn-on，不要只看 controller command；dead-time 太短/太長、leakage、magnetizing current、SR timing 都可能讓效率掉。

RESONANT CONVERTER

LLC：真正的油門是 switching frequency

Plant changes with operating point
① 白話

不是把 duty 從 40% 拉到 60%，而是改 fs，讓 tank 工作在 resonance 左右不同位置，藉由 impedance / circulating current 改 gain。

② 核心座標

先算 fr、Ln=Lm/Lr、fn=fs/fr、Q。這四個量比單看 Kp/Ki 更接近 LLC 的本體。

③ 控制

frequency-to-output gain 的斜率會跟 Vin/load 改；同一個 compensator 在不同 operating point 可能看到完全不同 plant。

④ Debug

瞬態慢不一定只是 PI 太小；先看 operating point 是否跑到 gain curve 很平、很陡或接近 mode boundary。

這裡用常見 normalized FHA 形式建立趨勢直覺；不同 FHA 定義、rectifier/load reflection 與實際磁性元件會改變係數。真正 loop design 要在目標 Vin/load operating points 量 SFRA 或建立對應 small-signal model。

DC → AC · STANDALONE / GRID-TIED

Inverter：AC 控制還多了同步與 filter resonance

LC/LCL + synchronization teaching model
① Standalone

目標是做出乾淨 Vac，常見 LC output filter + voltage loop，內層可再加 current loop。

② Grid-tied

目標通常是控制注入 grid 的 current；需要知道 grid phase，單相常用 SPLL / orthogonal signal generation，再做 PR 或同步座標控制。

③ LCL

多一顆 L 讓 switching ripple 更好擋，但也多出尖銳 resonance；沒有 damping 時，current loop 很容易在那裡出事。

④ Debug

current loop、PLL、outer DC-bus/power loop、LCL damping 都有自己的 bandwidth；彼此太靠近就會互相看見。

Magnitude 很早就掉

先查 analog/digital filter、多出來的 pole、sampling/ZOH、LLC operating-point slope。

Magnitude 差不多，phase 額外差

典型先查 ADC age、ISR、PWM shadow load、transport delay；Boost 還要看 RHPZ。

只在某 operating point 爛

Boost RHPZ 下移、PSFB ZVS energy 不夠、LLC plant slope 變、grid impedance 改變都屬這一類。

波形好看但效率差

PSFB/LLC 看 soft-switching、circulating current、dead-time；PFC 看 conduction path / zero crossing；inverter 看 switching/ripple current。

PFC bus 很穩但 THD 差

檢查 outer voltage loop 是否在追 2ω，current reference normalization / SPLL / zero-crossing 是否乾淨。

Inverter 某頻帶突然尖峰

先定位 LC/LCL resonance，再查 active/passive damping、PLL/current-loop bandwidth hierarchy。

模型分級：Exact = 可由獨立 identity 驗證；Teaching = 用來建立趨勢與第一性原理；Hardware = 必須靠實際 operating point、datasheet parasitic、scope/SFRA 才能閉環。
