🧮 C2000 馬達控制 ADC 參數計算器

專為 TI C2000 系列設計，協助驗證訊號鏈硬體設計與產生韌體 scaling 參數。

🔰 新手導覽：這個工具到底在算什麼？（建議先讀）

把 C2000 晶片想成馬達的「大腦」。它要隨時知道兩件事：(1) 流過馬達的電流有多大、(2) 供電的母線電壓有多高。

但晶片裡的 ADC（類比數位轉換器）只能讀 0V ～ 3.3V 的小訊號。問題來了：電流有好幾十安培、電壓有好幾百伏特，怎麼塞進這麼小的範圍？

解法：用一連串硬體電路把訊號「縮小＋平移」成 ADC 看得懂的電壓 → ADC 讀成 0～4095 的數字（count）→ 最後韌體用一組「還原係數」把數字換回真正的電流／電壓。

這個工具幫你：
① 確認硬體能不能把訊號剛好塞進 ADC 範圍、不會爆掉（飽和）。
② 自動算出韌體要用的還原係數與量測範圍。

👉 左邊填硬體規格 → 中間看電路與逐步計算 → 右邊拿到韌體參數。

⚡ 電流是怎麼被「量」到的？

電流看不見，所以用幾個步驟把它變成電壓：

  1. Shunt 分流電阻：讓電流流過一顆很小的電阻（如 0.005Ω），依歐姆定律 V=I×R 產生正比於電流的小電壓。電阻刻意做很小，是為了不浪費能量、不發燙。
  2. 放大器（Gain）：上一步電壓只有 mV 等級，ADC 看不清楚，所以放大（如 ×8.2）。
  3. 墊高（Offset）：馬達電流有正有負，但 ADC 只能讀 0V 以上。把「0 電流」對應到中間電壓（1.65V＝Vref 的一半），正電流往上、負電流往下，雙向都讀得到。

📏 幾百伏特怎麼降到 3.3V？

用「分壓電阻」把高壓按比例縮小：

V_adc = V_bus × R_bot / (R_top + R_bot)

R_top 用很大（如 2MΩ），因為功率損耗 P = V²/R，電阻越大、電流越小、發熱越少、越省電。高壓也常用「多顆電阻串聯」分攤（每顆都有耐壓上限），所以電路圖把 R_top 畫成一串。

📐 解析度 (bits) 與 LSB 是什麼？

解析度：12-bit 表示把 0～Vref 切成 2^N = 4096 格，讀出 0～4095 的整數。位元越多分得越細、越精準。

LSB（最小可分辨電壓）：一格代表多少電壓 = Vref ÷ FS ≈ 0.806 mV。小於這個量的變化，ADC 分不出來。

💡 為什麼要「墊高」(Offset)？

馬達電流會來回流動（正、負都有），但 ADC 只認得 0V 以上的電壓。不墊高的話，負電流會變成負電壓 → ADC 直接讀成 0，資訊就丟了。

所以把「0 電流」設在範圍中間（虛線）：正電流把訊號往右推、負電流往左推。上方長條的藍線就是目前訊號位置，待在範圍內就 OK，碰到兩端（紅字）就代表飽和、量不到了。把電流拉到 ±40A 試試看。

💻 4. 韌體參數 (Firmware)

這些係數負責把 ADC count 換回真實物理量。

💡 什麼是「還原係數 K」？為什麼需要它？

ADC 丟給韌體的只是一個數字（count，0～FS），它不是電流也不是電壓。韌體要把它「乘上一個係數」才能還原成真實物理量：

  • K_I：每 1 count 代表多少安培（換算時還要扣掉墊高對應的電流 I_offset）。
  • K_V：每 1 count 代表多少伏特。

這就是把第 3 區的計算「反過來做」。

⚠️ 什麼是「飽和」？為什麼要看最大範圍？

如果換算後的電壓超過 Vref（或低於 0），ADC 會被「截」在最大／最小值——再大的訊號都讀成同一個數字，量測就失真了。

上面的「Max Measurable」就是你這組硬體的極限。設計時要確保實際最大電流／電壓還留一點餘裕，不要剛好頂到。

Σ 公式總整理（速查表）

      
① 電流 → 電壓（Shunt）
V_shunt = I × R_shunt
  • I：流過的電流 (A)
  • R_shunt：分流電阻 (Ω)

      
② 放大 + 墊高 → ADC 電壓
V_adc = I × R_shunt × Gain + Offset
  • Gain：放大倍率 (V/V)
  • Offset：墊高電壓 (V)，通常 = Vref / 2

      
③ 分壓（高壓量測）
V_adc = V_bus × R_bot / (R_top + R_bot)
  • V_bus：母線電壓 (V)
  • R_top / R_bot：上、下分壓電阻 (kΩ)

      
④ ADC 取樣（電壓 → 數字）
count = V_adc / Vref × (2^N - 1)
  • Vref：ADC 參考電壓 (V)
  • N：解析度位元數

      
⑤ 韌體還原係數
K_I = LSB / (R_shunt × Gain)
K_V = LSB × (R_top + R_bot) / R_bot
  • LSB = Vref / (2^N - 1)
  • K_I：A/count；K_V：V/count

    


    

      
📖 名詞小辭典

      
分流電阻 Shunt Resistor
很小的電阻，讓電流流過產生正比的小電壓，藉此「間接量電流」。電阻小才不會發熱、不浪費能量。

      
增益 Gain
放大器的放大倍率。Shunt 產生的電壓只有 mV 等級，放大後 ADC 才看得清楚。

      
墊高電壓 Offset
刻意加上的直流電壓（常為 Vref 一半），讓「0 電流」落在範圍中間，正負電流都量得到（雙向量測）。

      
參考電壓 Vref
ADC 能讀到的最高電壓。輸入超過它就「飽和」，讀數被截住。

      
解析度 / LSB Resolution / LSB
N-bit 把 0～Vref 切成 2^N 格。LSB = Vref/(2^N−1)，是 ADC 能分辨的最小電壓變化。

      
滿刻度計數 Full Scale
ADC 能輸出的最大數字 = 2^N − 1（12-bit 為 4095）。

      
分壓比 Divider Ratio
R_bot/(R_top+R_bot)，把高壓按比例縮小到 ADC 範圍的倍數。

      
飽和 Saturation
訊號超出 0～Vref，ADC 被截在最大/最小值，量測失真。設計要留餘裕避免。

      
還原係數 K factor / Scale
韌體把 ADC 數字乘上它，換回真實的電流（A）或電壓（V）。
