Σ 公式總整理

① 電流 → 電壓（Shunt）· 第2課
V_shunt = I × R_shunt
  • I：電流 (A)；R_shunt：分流電阻 (Ω)
② 放大 + 墊高 → ADC 電壓 · 第2~3課
V_adc = I × R_shunt × Gain + Offset
  • Gain：放大倍率；Offset 通常 = Vref/2
③ 分壓（高壓量測）· 第4課
V_adc = V_bus × R_bot / (R_top + R_bot)
  • R_top/R_bot：上、下分壓電阻 (kΩ)
④ ADC 取樣（電壓 → 數字）· 第1課
count = V_adc / Vref × (2ᴺ − 1)
  • Vref：參考電壓；N：解析度位元
⑤ 韌體還原係數 · 第5課
K_I = LSB / (R_shunt × Gain) K_V = LSB × (R_top + R_bot) / R_bot LSB = Vref / (2ᴺ − 1)
  • K_I：A/count；K_V：V/count
⑥ 電阻發熱（設計檢查）· 第4課
P_Rtop ≈ V_bus² / R_top
  • R_top 越大越省電

📖 名詞小辭典

分流電阻 Shunt Resistor
很小的電阻，讓電流流過產生正比小電壓，間接量電流。電阻小才不發熱。
增益 Gain
放大器倍率。Shunt 電壓只有 mV，放大後 ADC 才看得清。
墊高電壓 Offset
刻意加的直流電壓（常為 Vref 一半），讓 0 電流落在中間，雙向都量得到。
參考電壓 Vref
ADC 能讀到的最高電壓。超過就飽和。
解析度 / LSB Resolution / LSB
N-bit 把 0~Vref 切成 2ᴺ 格。LSB = Vref/(2ᴺ−1)，最小可分辨電壓。
滿刻度 Full Scale
最大數字 = 2ᴺ − 1（12-bit 為 4095）。
分壓比 Divider Ratio
R_bot/(R_top+R_bot)，高壓縮小的倍數。
飽和 Saturation
訊號超出 0~Vref，讀數被截，量測失真。設計要留餘裕。
還原係數 K factor / Scale
韌體把 count 乘上它，換回真實電流 (A) 或電壓 (V)。
餘裕 Headroom
實際最大值離飽和還剩多少％，建議保留 10~20%。
