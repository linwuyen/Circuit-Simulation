SPI 怎麼送資料 + 反向設計計算機

這一課你會懂:那 16 個 bit 是怎麼透過 SPI 送進晶片的;並學會反過來算「我要輸出某個電壓,該寫什麼 hex 碼」,還能直接產生 MCU 程式碼。

🔌
SPI 是一條「一個一個 bit 排隊送」的序列介面。流程:CS 拉低開始 → 沿著 CLK 邊緣,把 bit15…bit0(MSB 先送)推進晶片裡的移位暫存器 → CS 拉高鎖存,DAC 同時更新輸出。 下面波形的 SDI 線,高低起伏就是你目前數位碼的每一個 bit。

📌 重點整理 + 全課總結

    
    
      
  • SPI 送碼三步:CS↓ → 沿 CLK 推 16 bit(MSB 先) → CS↑ 鎖存更新。
    • 
      
  • 正向:VOUT = ±VREF × (D/2¹⁶);反向:D = round(目標比例 × 2¹⁶),再轉成 hex 送出。
    • 
      
  • 整門課串起來:數位碼 → R-2R → IOUT → TIA/RFB → VOUT,再加上極性選擇、線性、誤差校正與 SPI 通訊,就是一條完整可用的訊號鏈。🎉
