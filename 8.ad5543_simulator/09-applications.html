第 9 課 · 進階應用

應用情境:把乘法 DAC 當「數位旋鈕」用

這一課你會懂:既然輸出 = VREF × 比例,只要把 VREF 換成你的訊號,DAC 就變成一個用數位碼控制的衰減器 / 可程式增益,還能做波形縮放與自動校正。

🎛️
前 8 課都把 VREF 當「固定直流」。但乘法 DAC 的精髓是:VREF 可以是會動的交流訊號。 這時輸出 = 輸入訊號 × (D/2¹⁶) —— 等於一顆用程式碼轉動的音量旋鈕。

基本接法是衰減(0 ~ 1 倍);若把 DAC 放到運放的回授路徑,就反過來變成可程式增益放大器(PGA,增益 = 2¹⁶/D)。 下面的 demo 用一個正弦輸入,讓你拉數位碼即時改變輸出大小與相位。
🧪 動手試試
  1. 拉 數位碼:看綠色輸出正弦的振幅跟著縮放,右側增益(倍率與 dB)即時更新。
  2. 碼設一半(0x8000)→ 輸出約為輸入的 0.5 倍(−6 dB);碼設 0 → 輸出靜音。
  3. 切換 相位:標準(反相)時輸出與輸入上下相反,正輸出則同相。
  4. 調 輸入振幅(VREF):這代表你餵進去的交流訊號大小。

🧰 常見應用一覽
🔊 數位音量 / 衰減器

把音訊或感測訊號接到 VREF,用數位碼即時調整大小(0 ~ 1 倍),無機械電位器、可程式、可重現。

📈 可程式增益放大器 (PGA)

把 MDAC 放進運放回授路徑,增益變成 2¹⁶/D,可用程式碼選擇放大倍率,常見於量測前端。

〰️ 波形產生 / 縮放

VREF 餵入參考波形,連續更新數位碼即可做振幅調變(AM)、包絡控制或任意波形縮放。

🎯 自動校正 / 微調源

當作高解析度的可程式電壓/增益微調(trim),取代手調可變電阻,做產線自動校正。

🔧 增益微調 (Gain Trim)

串在訊號鏈中對既有增益做 ±少許百分比的精細修正,補償元件容差。

🧪 四象限相乘

VREF 與碼皆可正負 → 真正的類比相乘器,可做相位敏感偵測等運算。

📌 重點整理 · 課程總結
  • 把 VREF 換成會動的訊號,乘法 DAC 就是數位控制的旋鈕:輸出 = 訊號 × (D/2¹⁶)。
  • 基本接法是衰減(0~1×);放進回授路徑則成可程式增益(PGA)。
  • 整套課:比例旋鈕 → 位元 → R-2R/IOUT → TIA/RFB → 極性 → 線性 → 誤差校正 → SPI → 應用。你已經走完一條完整訊號鏈!🎓
