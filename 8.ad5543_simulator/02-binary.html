數位碼與位元:那個「旋鈕值」怎麼用 16 個 0/1 表示

這一課你會懂:16-bit 數位碼是怎麼由 0 與 1 組成的,每個位元(bit)有不同權重,MSB 最大、LSB 最小。

🔢
十進位裡,左邊的位數比較大(百位 > 個位)。二進位也一樣:最左邊的 bit15 權重 = 32768,最右邊的 bit0 權重 = 1。 把所有「是 1」的位元權重加起來,就是這個數位碼。例如 0x8000 只有最高位是 1 → 等於 32768 → 剛好是中刻度(一半)。
🧪 動手試試
  1. 下方暫存器,只點亮最左邊那格(bit15)。看上面數值變成 32768 = 0x8000 —— 一個 bit 就佔了一半。
  2. 再點亮 bit14。數值變 49152(32768 + 16384 = 佔 3/4)。
  3. 全部點亮 → 65535 = 0xFFFF(滿刻度)。再全部關掉 → 0。
  4. 觀察:每點亮一個越右邊的位元,輸出只動一點點 —— 那就是它的「精細度」。
🧮 16-bit 暫存器(點一下翻轉某一位元)
左 = MSB(權重大) → 右 = LSB(權重小)
📌 重點整理
  • MSB(bit15)權重 32768、LSB(bit0)權重 1;數位碼 = 所有為 1 的位元權重總和。
  • 16 bit → 共 65536 個不同的階(0 ~ 65535),這就是「16 位元解析度」的意思。
  • hex(十六進位)只是把 16 個 bit 每 4 個一組寫得更短:0x8000、0xFFFF。送進晶片時用的就是這個值。
