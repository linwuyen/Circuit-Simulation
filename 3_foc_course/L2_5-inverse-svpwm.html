占空比 D = 0.5 + (相電壓 + 共模)/2，必須落在 0~1 之間。
取消勾選共模 → 退回純正弦 SPWM，極限只到 0.5。
🎯 動手試 看右圖三條占空比：勾選共模時是中間凹的馬鞍波；取消勾選變回純正弦。把 |V| 拉到 0.5 以上，純正弦會頂到 1（飽和），但馬鞍波還撐得住 —— 這就是 SVPWM 多出來的約 15% 電壓。
💡 你學到了 反 Clarke 把 αβ 拆回三相 Va/Vb/Vc；SVPWM 再疊一個共模（≈3 次諧波，三相同步加減、不影響線電壓），把每相壓低，於是線性區從 SPWM 的 0.5 撐到 0.577（內切圓 1.0）。左圖扇區告訴你此刻該用哪兩個基本向量 V1–V6 合成。
