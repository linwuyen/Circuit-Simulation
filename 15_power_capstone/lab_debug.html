B-ceiling Debug Discipline

Power → Clock → Reset → Signal → Timing → Data → State → Control → Plant

未知系統的除錯先從最低層 invariant 開始。PWM 根本不存在時先調 PI，只是在高階層製造更多變數。

—

—
Transfer：這個順序不是僵化 SOP；核心原則是「先證明更低層的 necessary condition」。若某系統沒有 clock/reset 這層，就用最接近的 causal dependency 取代。
