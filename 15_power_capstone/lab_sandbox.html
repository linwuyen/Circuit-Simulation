進階模式：觀察同一台電源的完整運作

把它想成一台透明的虛擬電源：Host 給命令 → DMA/資料交給控制器 → ADC 取樣 → PI 算 duty → PWM 驅動 power stage → sensor 再量回來。任何一段出錯，後面的波形都會真的跟著變。

先記三句話：① ADC 量到什麼，控制器就相信什麼。② duty 算得太晚，就只能再用一拍舊 duty。③ 進 FAULT 時，不管 PI 算多少，PWM 都必須關掉。

1. 先設定你想要的輸出

預設先命令 24 V，之後跳到 48 V。這樣 stale command 才會真的看得出來。

電感飽和採平滑的微分電感下降曲線，只用來觀察電流斜率與保護；不含磁滯、磁芯損耗或溫升，不能用來選實體磁芯。

2. 控制器什麼時候看到資料、什麼時候更新 PWM

這裡最重要的不是數字本身，而是順序：開始取樣（SOC）→ 轉換完成（ADC EOC）→ 執行中斷程式（ISR）→ 計算完成 → 更新開關命令（PWM commit）。最後一步超過 period，就真的 miss。

虛擬示波器：看電壓與電流怎麼變

Vout、inductor current、applied duty 都來自同一個 run。注意 applied duty，不要只看 controller 算出的 duty。

同一條時間軸

資料、ISR、PWM commit、trip 都放在一起，才能回答「誰先發生」。

白話 Debug 順序：輸出不對時先問「命令新不新？」→「ADC 量得對不對？」→「duty 算得對不對？」→「duty 有沒有真的套用？」→「是不是安全狀態把 PWM 關掉？」。不要第一個動作就調 PI。
