Signal

量到什麼，就控制什麼

scale、offset、sample point 錯了，controller 就會對錯誤的世界做出「數學上合理」的決定。

Timing

算完不等於套用了

control 算得太晚，錯過 PWM load point，就只能再用一拍舊 duty。

Safety

State 有最後否決權

只要進 FAULT，PWM 就必須 OFF；control command 不能凌駕 safety invariant。

Diagnosis

量最有用的，不是量最多

用 DMM、ADC、duty、sequence、timing 一步步排除原因，而不是看到 Vout 不對就先改 PI。

Unified Engineering Sandbox

五個 lab 現在共用同一台 hidden machine

以前 DMA、State、Multi-fault、Code Trace 比較像各自示範一個觀念。現在它們都使用同一個 causal kernel：資料舊了會真的讓 command 落後；timing miss 會真的留下舊 duty；FAULT 會真的關 PWM；code mutation 會真的重跑 plant。

同一台虛擬電源DMA → commandState → PWMLive Multi-FaultCode → Physical
公開邊界：這不是任何公司產品的 clone。所有 topology、數值、fault 與 code 都是 generic teaching model，只訓練可遷移的 sensing / timing / ownership / safety / control / diagnosis 能力。
