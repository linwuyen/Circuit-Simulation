Signal

Timing

算完不等於套用了

Safety

Safety 可以否決 control

只要進 FAULT，PWM 就必須 OFF；control command 不能凌駕 safety invariant。

Diagnosis

量最有用的，不是量最多

每一步選最能縮小假設空間的 observable；不要看到 Vout 不對就先改 PI。

UNKNOWN-SYSTEM PRACTICE

五個 lab 共用同一台 hidden machine，但你不先看到 root cause

DMA、State、Multi-fault、Code Trace 都使用同一個 causal kernel：資料 stale 會讓 command 落後；timing miss 會留下舊 duty；FAULT 會關 PWM；code mutation 會重跑 plant。你的任務不是把每個 slider 玩一遍，而是先提出假設，再選一個最高資訊量量測。

同一台虛擬電源DMA → commandState → PWMLive Multi-FaultCode → Physical
使用規則：先證明 signal existence，再證明 timing，再證明 numerical correctness / ownership / state，最後才改 control algorithm。這裡訓練的是 diagnosis transfer，不重新教一次 Module 19。
公開邊界：這不是任何公司產品的 clone。所有 topology、數值、fault 與 code 都是 generic teaching model，只訓練可遷移的 sensing / timing / ownership / safety / control / diagnosis 能力。
