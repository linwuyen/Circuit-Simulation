先建立腦內模型

三種變換，各自在回答什麼問題？

白話

Laplace：這個系統天生會怎麼動？

像敲一下彈簧：它會慢慢停、一直震，還是越震越大？Laplace 把「微分方程」換成 pole / zero，讓穩定、速度、振盪直接看得到。

微分 → ×s　　積分 → ÷s
白話

Fourier：拿不同頻率去敲，它怎麼回？

10 Hz、100 Hz、1 kHz 一個一個丟進去，看輸出放大幾倍、落後幾度。Bode plot 就是把所有頻率的結果排成一張圖。

s = jω
白話

Z：MCU 每一拍看一次，狀態怎麼變？

類比世界連續流動，MCU 卻是 sample → compute → update。Z-transform 把「上一拍」變成 z⁻¹，最後就能直接寫成 C code。

z⁻¹ = one-sample delay
一句話：Laplace 看自然動態；Fourier 看頻率響應；Z 看取樣後每一拍的動態。三者不是三門分離的數學，而是同一個 LTI 系統的不同觀察方式。

A-CAPABLE LAB · ONE POLE, THREE VIEWS

拖一顆 pole，看「穩不穩」為什麼會跨域保持一致

STABLE
① 白話直覺

如果一個擾動每過一段時間都變小，最後自然會消失，所以系統穩定。

② 數學原因

σ<0 時 eσt 會衰減；取樣後每拍倍率 |z|=eσTs<1。

③ MCU 世界

連續 pole λs 經取樣後變成 z=eλsTs。狀態空間的 exact ZOH 也有 Ad=eATs。

④ Debug 問法

看到振鈴時，不先亂調 Kp。先問：pole 靠近穩定邊界嗎？sampling / delay 是否把離散 pole 推向 unit circle？

時間響應：你實際看到的振鈴

s-plane：連續時間的座標

左半平面：Re(s) < 0 → 衰減 → 穩定。jω 軸就是 Fourier 的觀察線。

z-plane：每一拍的座標

為什麼 ω 不影響 |z|？

因為 z=e(σ+jω)Ts=eσTs·ejωTs。前半段決定半徑，後半段只是旋轉角度。所以 σ 決定「往內縮或往外長」，ω 決定「每拍轉多少角度」。

正式驗證項目：工作單會把頁面顯示的 |z| 與獨立解析式 exp(σTs) 比對；兩者不是共用同一段 simulator 計算。

DEMO 2 · DIGITAL DELAY

「只是晚一點更新 PWM」為什麼會吃掉 phase margin？

① 白話直覺

如果輸入已經轉到下一個角度，你卻還用舊資料做反應，就像方向盤永遠慢半拍；頻率越高，同樣 10 µs 代表的「角度落後」越大。

② 數學原因

純延遲 e−sTd 在 jω 軸上 magnitude=1，但 phase=−ωTd，所以它不太改增益，卻會直接從 phase margin 扣分。

③ C2000 實機

真正 latency 要從 ePWM SOC 算到 ADC acquisition / conversion、ADCINT、ISR、control compute，再到 CMPA shadow 真正 load。

④ Debug 問法

模型 PM 60°、SFRA 只剩 30°？先量 GPIO ISR timing、確認 PWM load event，再查 ADC filter / ZOH，而不是先亂改補償器。

DEMO 3 · PI = POLE + ZERO

調 Kp / Ki，不是調兩個魔法數字，而是在移動頻率結構

① 白話直覺

Ki 負責「誤差拖太久就越來越用力」，所以能消掉 steady-state error；Kp 負責「現在錯多少就立刻推多少」。

② 數學原因

PI 可重寫成 Kp(s+Ki/Kp)/s：一顆 pole 固定在 0，一顆 zero 在 ωz=Ki/Kp。調參其實是在移 zero 與整體 gain。

③ MCU 實作

離散化後會變成 u[n]=u[n−1]+b0·e[n]+b1·e[n−1]。z⁻¹ 最後就是上一拍變數。

④ Debug 問法

先找 plant pole/zero、目標 crossover、需要補 phase 的頻帶，再決定 PI zero；不要只看 transient 然後盲調 Kp/Ki。

PI frequency response

真正的設計問題不是「Kp 要多少？」而是 plant 的 pole/zero 在哪、crossover 要放哪、需要在哪一段補 phase。

MODEL → MEASUREMENT

SFRA 不是「幫你畫 Bode」而已：它是在問模型到底漏了什麼

① 白話直覺

在迴路裡偷偷加一個很小的正弦擾動，掃很多頻率，看看系統每個頻率怎麼回。

② 頻域

SELF CHECK

三題確認你是真的打通，不是只看過

1. σ 從 −200 拉到 0，會發生什麼？

時間域不再衰減；s-plane pole 到 jω 軸；z-plane 半徑到 |z|=1。三個現象是同一件事。

2. Td 不變，fc 從 5 kHz 加倍到 10 kHz？

phase lag 也加倍。因為 φ=−360fTd；同樣的時間延遲，在更快的波形上佔了更大的角度。

3. Ki/Kp 變大，PI zero 往哪裡走？

ωz=Ki/Kp 變大，所以 zero 往高頻移；積分器主導的區域延伸到更高頻。

最後真正要留下的是這個腦內模型

s = σ + jω Fourier = Laplace @ s = jω z = esTs DTFT = Z-transform @ |z| = 1
